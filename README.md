# Star: All-in-One AI Agent & Studio
Star is a native Android AI agent, video editor, and 2D animation studio built entirely on-device.
- **AI Agent:** Run local or cloud LLMs to automate tasks.
- **Video Editor:** Concat-powered NLE timeline.
- **2D Studio:** Frame-by-frame animation, rigging, and GPU-accelerated drawing.
## Building
Built in Termux. See `docs/STAR_LONG_STATE.md` for build instructions.
